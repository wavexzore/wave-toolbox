## 1. 实施结论

在李跳跳 2.2 完整还原源码（`third_party/litiaotiao_analysis/`）和 gkd 规则体系的双重证据下，本特性不需发明新机制：**把已验证的"关键词→过滤→Y 最小优先→可点击祖先→重试预算"语义移植到基座的规则引擎上**，用 JSON5 规则包承载，收益是获得版本化、可单测、可回归的规则体系。

## 4. 目标方案

### 4.1 目标链路

```text
[基座]事件分发(ctx)
  -> AdSkipFeature.onEvent: 作用域检查（开关/名单/模式/包名）
  -> 模式= splash: 仅当 activity 变化且为"首个稳定窗口"（或 rules 声明 splash 类）
  -> [基座]RuleEngine: 取 adskip 组规则（pkg+activity+version 预筛）
  -> 关键词优先序：用户 extra 关键词 > 内置默认关键词 > view-id 规则
  -> 过滤(c 语义) -> 选中 Y-min -> [基座]ActionExecutor.click(可点击祖先→坐标)
  -> 账本/统计/日志
```

关键约束：

1. 微信等白名单 App 依赖基座服务组件伪装类名（D-011）：空树=407B 特征，任何跳过规则都不会命中。
2. 特性关闭时零动作、仅入库统计为 0。
3. 单次事件最多触发一次点击（防连点由基座账本兜底）。
4. 规则文件不得写死屏幕坐标（除明显固定位置的坐标规则，且用百分比）。

### 4.2 设计决策

| D-ID | 决策 | 理由 | 拒绝方案 | 影响任务 |
|---|---|---|---|---|
| D-101 | schema 对齐 gkd 字段子集（`matches/action/actionCd/actionMaximum/activityIds/version*`） | 迁移成本低、生态心智一致 | 自定义+yaml | T-001 |
| D-102 | 关键词匹配默认"包含"且要求文本长度 ≤ 6 字符（"跳过广告"OK，"跳过登录"由 exclude 排除） | 防误点 | 全等匹配（漏"跳过 3s"变体） | T-002 |
| D-103 | Y-min 排序 + 顶部区域优先（Y<屏高 25%） | 李跳跳取 Y 最小；开屏跳过按钮集中在右上/顶部 | 全部候选逐一试 | T-002 |
| D-104 | 过滤规则照搬并文档化（editable/checkable/scrollable/宽>60%无文本/不可见） | 误点主要来源 | 不过滤 | T-002 |
| D-105 | `mode`（splash/any）二分 + `perApp` 名单 | 用户预期"跳过开屏"，全局弹窗是有用附加但需可控 | 只做开屏（损失价值） | T-004 |
| D-106 | `path`/`position` 规则最后执行 | 脆弱性最高 | 优先执行（可能点错） | T-005 |
| D-107 | 年轻弹窗延迟：CONTENT_CHANGED 源首次出现延迟 150ms 再点 | 防"刚显示尺寸未稳"误点 | 立即点 | T-002 |
