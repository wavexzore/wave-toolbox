| 现象 | 证据（stat_records / 日志） |
|---|---|
| 打开微信被自动切到"通讯录" | 基座内置演示规则 `demo.mm@contactsTab` ACTION **56 次**；`demo.chrome@more` 8 次、`demo.settings@search` 1 次（引擎侧 65 次点击全部来自演示规则） |

| 同秒连点 | "我知道了" 1 秒内 4 次（失败重试） |

| 用户实报：MT管理器「Activity 记录」弹窗被误关 | 弹窗（cls=l.᩵ܿ、text=Activity 记录、wrap_content 小窗）出现即被点"关闭" |

### 12.2 修复内容

| 项 | 级别 | 实现 | 文件 |
|---|---|---|---|
| 演示规则默认关闭 | P0 | 4 个内置演示规则 assets `enabled:false`（`importBuiltin` 每次整源替换会覆盖 DB 开关，必须改 assets）；保留 `mm@LauncherUI.splash` | `core/rules/src/main/assets/rules/builtin/*.json5` |
| 非前台不点 | P0 | 新增 `WindowTreeProvider.isAppForeground(pkg)`（主屏无其它应用占焦才放行）；onEvent 前置守卫 | `NodeAdapter.kt` / `AdSkipFeature.kt` |
| 开屏窗口收紧 | P1 | 10s → 5s；窗口起点改为"进入前台/真实 Activity 切换"（去掉同 Activity WSC 反复刷新）；实例态随新实例清理防膨胀 | `AdSkipFeature.kt` |
| 非 Activity 窗口不重置窗口 | P1 | 双重判别：类名非框架类且带包名点号（`looksLikeActivity`）+ 焦点窗口非小窗（`focusedWindowBounds`，<90% 屏视为弹窗）；抽屉/对话框不再触发新一轮点击；保守模式（仅开屏）仅在全屏窗口上点击，小窗一律跳过——从根上避免"用户刚打开的弹窗被顺手点掉" | `AdSkipFeature.kt` / `NodeAdapter.kt` |
| 连点防护 | P1 | 同实例尝试最小间隔 500ms + 每实例点击预算（成功上限+2，失败才消耗）；`tree=null`/无候选不消耗预算 | `AdSkipFeature.kt` |
| 易误点关键词约束 | P1 | `关闭`=顶部 35% 区域或自/祖先可点击；`×/✕`=右上角或可点击；`跳过` 等不约束 | `KeywordStrategy.kt` |
