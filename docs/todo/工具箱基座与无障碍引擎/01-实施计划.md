## 1. 实施结论

仓库当前只有 `docs/`、`.gitignore` 与只读的 `third_party/`（李跳跳逆向资料），没有任何可构建代码。本计划从零建立 **Kotlin + Jetpack Compose** 的多模块 Android 工程，并实现一个 **自研无障碍引擎**：事件管线、选择器匹配、动作执行、任务编排、保活与 Feature SPI。

路径选择依据：arXiv 2609.17316（2026）对 108 种广告拦截方案的系统评估显示，唯一在全部 10 个目标 App 上成功拦截的方案是 **Accessibility 权限方案**（其余需要 root / 运行时注入 / 改包）；gkd（42k star，Kotlin）验证了"事件合流 + 选择器预编译 + 单线程调度 + 1×1 overlay 保活"的工程可行性；worktool（Apache-2.0）验证了"主动任务状态机 + ANR 自愈"在微信系自动化上的可行性。李跳跳的完整还原源码（`third_party/litiaotiao_analysis/source`）为本仓库提供第一手规则语义参考。本地姊妹项目 `wavexzore-ledger` 的实机实证（D-014/PIT-004）补充了关键硬约束：**微信按服务组件类名白名单发布节点树**，服务类必须伪装为 `com.google.android.accessibility.selecttospeak.SelectToSpeakService`，否则微信发布空树（407B）——已固化为 D-011。

最小安全切片：**先让一个空壳特性跑通"事件 → 规则 → 选择器 → 点击"全链路（T-001 ~ T-010）**，两个业务特性（`splash-ad-skipper`、`wechat-zombie-cleaner`）各自独立成目录、独立任务队列，依赖本计划的任务 ID 交付。

明确不做：内置 JS 引擎、OCR、root、远程订阅（见 §5.3）。LLM 应从 `T-001` 开始。

## 4. 目标方案

### 4.1 目标链路

```text
AccessibilityService.onAccessibilityEvent(event)
  -> EventPipeline.filterAndEnqueue(event)        // 丢弃无用事件、节流、归一化
  -> eventDispatcher 单线程 consume
  -> FeatureRegistry.dispatch(ctx)                // 按包名/开关分发
  -> RuleEngine.match(rules, snapshot) | TaskOrchestrator.step(ctx)
  -> ActionExecutor.perform(target, action)       // 点击链/手势/全局动作
  -> Stats + Log + (可选) FloatingProgress
```

### 4.2 设计决策

| D-ID | 决策 | 理由 | 拒绝方案 | 影响任务 |
|---|---|---|---|---|
| D-001 | Kotlin + Jetpack Compose + Material3；minSdk 26、targetSdk 36、compileSdk 37（BOM 2026.09 要求 ≥37，T-002 校准） | 官方推荐；gkd 同栈验证；Compose 提升 UI 迭代效率 | XML+View：样板多；Flutter/KMP：收益低 | T-001,T-002 |
| D-002 | 自研引擎 + Feature SPI | 可测、可控、无许可绑定 | fork gkd（GPL）；嵌 AutoJs6（重） | 全部 |
| D-003 | `NodeView` 纯数据抽象 + `AccessibilityNodeInfo` 适配器；选择器/匹配器纯 JVM | 让 90% 逻辑可在 JVM 单测，设备只做端到端 | 直接依赖 `AccessibilityNodeInfo`（无法 JVM 测试） | T-005 |
| D-004 | 规则 JSON5（`li.songe:json5`，Apache-2.0） | 注释/尾逗号友好；gkd 生态同格式可借鉴 | 纯 JSON（写规则体验差）；自研解析器 | T-006 |
| D-005 | 保活 = 1×1 `TYPE_ACCESSIBILITY_OVERLAY` + FGS(specialUse) 常驻通知 + BOOT_COMPLETED + OEM 引导 | 三重独立机制互补；均有上游验证 | 巨响铃/双进程互拉（复杂度高） | T-009 |
| D-006 | 三组单线程 CoroutineDispatcher（event/query/action）+ CONTENT_CHANGED 100ms 节流 | gkd 实测防 ANR 方案 | 线程池（顺序与背压难控） | T-004 |
| D-007 | Hilt(KSP) DI + 手写简单单例约束 | 官方推荐、编译期校验；Service 注入需 `@AndroidEntryPoint` | Koin（运行时错误晚暴露） | T-002 |
| D-008 | DataStore(设置) + Room(规则/历史) + assets 内置规则 | 查询/事务/迁移成熟；替代 MMKV 省 native 依赖 | MMKV（native 体积）；SharedPreferences（弱） | T-006,T-011 |
| D-009 | SPI 以 Hilt multibinding 注册 `ToolFeature` | 新功能零改引擎 | 反射扫描（慢/易错） | T-010 |
| D-010 | 许可证 = Apache-2.0（Q-002 已定）；与 gkd 的 GPL 边界：只借鉴设计不复制代码；若日后复制其代码则重评（整体改 GPL-3.0） | 保留许可自由度 | 直接复制代码（绑定 GPL） | 全部 |
| D-011 | 无障碍服务组件类名固定伪装 `com.google.android.accessibility.selecttospeak.SelectToSpeakService`（类真移包；Manifest `android:name` 与全限定名一致；**冻结不改**） | 微信空树门禁（ledger D-014 实证 407B→90KB A/B）；生态惯例（阿柴/小米钱包同款） | 自有类名（微信空树）；仅改 Manifest 不迁类（无法绑定伪装名） | T-003 |
| D-012 | 构建工具链锁定：AGP 9.4.1 + Gradle 9.6.1 + Kotlin 2.3.21 + KSP 2.3.12 + Hilt 2.60.1，配 `android.builtInKotlin=false`、`android.newDsl=false` 兼容开关 | 与 wavexzore-ledger 同源且本机实证（同组合已产出 app-debug.apk）；AGP 9 默认 built-in Kotlin 与 `kotlin.android` 插件互斥（实测报错），opt-out 为官方支持路径 | AGP 8.x/Kotlin 2.2.x（与本机缓存不匹配）；AGP 9 built-in Kotlin（Compose/KSP/Hilt 组合未验证） | T-001 |
