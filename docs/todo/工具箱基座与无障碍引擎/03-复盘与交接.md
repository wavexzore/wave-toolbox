## 6. 维护指南

| 操作 | 命令/入口 | 说明 |
|---|---|---|
| 构建 | `./gradlew :app:assembleDebug` | 出 debug 包 |
| 全量验证 | `./gradlew test lint` | CI 同款 |
| 快照导出 | App 内 日志/检查器页 | 导出当前窗口树 JSON |

| 配置 | 推荐值 | 注意事项 |
|---|---|---|
| `engine.contentThrottleMs` | 100 | 调低增耗电，调高迟钝 |
| `engine.enabled` | true | 用户可关 |
