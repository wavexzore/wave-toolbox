## 6. 维护指南

### 6.1 常用操作

| 操作 | 入口 | 说明 |
|---|---|---|
| 失败定位（检测） | `files/wechat_fail/{runId}/` 快照 | 对照锚点表修复 |
| 失败定位（删除） | 条目"失败"原因 + 快照 | 修复后重跑仅处理剩余 |
| 回归 | `./gradlew :feature:wechat:test` | fixtures 驱动 |
| 版本升级适配 | 新版本先 dry-run，后小批量试删 | 更新锚点/文案样例 |

### 6.2 配置说明

| 配置 | 推荐值 | 注意 |
|---|---|---|
| `wechat.batchSize` | 30 | 硬上限 39 |
| `wechat.dryRun` | 首轮 true | 群保留 |
| `wechat.delete.defaultSelection` | `deletedOnly` | 默认仅预选"已删除你"类 |
| `wechat.delete.withHistory` | `false` | false=保留聊天记录 |

### 6.3 日志与排查

| 场景 | 位置 | 判断 |
|---|---|---|
| 卡某步 | 任务日志 step/timeout | 锚点是否命中 |
| 分类错误 | record.rawMessage | 解析器 vs 文案样本 |
| 删除被跳过 | 条目原因（名称不符/资料页空） | NameVerifier 记录 vs 真实昵称 |
| 全页面零锚点命中 | 先跑 `C-205` 空树预检 | 407B/根 null=服务组件名问题（非锚点问题） |
